# AGROSCORE — Competitor Inspiration Pack

This bundle is meant to be uploaded into GPT/Codex/VS Code so the model can understand:
1. what the closest agri-credit products already do,
2. which UI/product patterns are worth borrowing,
3. which claims are no longer differentiated,
4. what AGROSCORE should look and feel like for a hackathon demo.

## Recommended instruction to the coding model

Read every file in this folder before changing code.

Do **not** clone any competitor pixel-for-pixel.
Use the research to synthesize a stronger institutional B2B underwriting interface.

Target visual synthesis:
- **Traive:** institutional credit workflow + strong amount hierarchy
- **TerraMagna:** map + portfolio/risk monitoring + alerts
- **SatSure:** parcel-level earth intelligence + lender-oriented framing
- **Nera:** financing clarity and simple, understandable financial flows

AGROSCORE must remain differentiated around:
- requested amount vs **recommended exposure**
- stress testing that immediately changes safe exposure
- explicit separation of **Financial Capacity vs Productive Resilience**
- explainable score contributions ("WHY 82?")
- Argentina-specific data stack
- future programmable disbursements / continuous risk monitoring

Do not claim that generic AI scoring, satellite monitoring, continuous monitoring, or CUIT-only credit evaluation are unique. Competitors already do these.
